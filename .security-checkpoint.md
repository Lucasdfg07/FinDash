## Task 1.3: Security Headers ✅

### Headers Configurados:
1. **X-Content-Type-Options: nosniff** - Previne MIME sniffing
2. **X-Frame-Options: DENY** - Previne clickjacking
3. **X-XSS-Protection: 1; mode=block** - Proteção XSS
4. **Referrer-Policy: strict-origin-when-cross-origin** - Controla Referer
5. **Permissions-Policy** - Bloqueia camera, mic, geolocation
6. **Strict-Transport-Security** - HSTS (31536000s = 1 ano)
7. **Content-Security-Policy** - Restritiva mas funcional

### Arquivo:
- `next.config.ts` - Headers automaticamente aplicadas em todas respostas
