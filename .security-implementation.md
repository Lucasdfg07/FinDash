## 🔍 Validação de Funcionalidade

### Rate Limiting
```bash
# Teste: 5 requisições em 1 minuto
curl -X POST http://localhost:3000/api/inter/sync \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{"dataInicio":"2026-01-01","dataFim":"2026-02-20"}'

# Resposta esperada (6ª requisição):
# HTTP 429
# {
#   "error": "Too many requests",
#   "message": "Rate limit exceeded. Try again in 3600 seconds."
# }
# Headers:
#   Retry-After: 3600
```

### Autenticação
```bash
# Teste: SEM token
curl -X GET http://localhost:3000/api/inter/status

# Resposta esperada:
# HTTP 401
# {
#   "error": "Unauthorized",
#   "message": "Authentication required. Please log in."
# }

# COM token:
curl -X GET http://localhost:3000/api/inter/status \
  -H "Authorization: Bearer {token}"
# HTTP 200 + dados
```

## 🏗️ Arquitetura de Segurança Implementada

```
REQUEST
   ↓
┌─────────────────────────────────────┐
│ 1. Rate Limiting (checkRateLimit)   │ ← Bloqueia DoS
│    - Por IP/User                    │ ← 429 Too Many Requests
└─────────────────────────────────────┘
   ↓ (se ok)
┌─────────────────────────────────────┐
│ 2. Autenticação (requireAuthMiddleware) │ ← Verifica session
│    - getServerSession               │ ← 401 Unauthorized
└─────────────────────────────────────┘
   ↓ (se autenticado)
┌─────────────────────────────────────┐
│ 3. Input Validation (Zod Schema)    │ ← Valida tipos
│    - schema.parse(body)             │ ← 400 Bad Request
└─────────────────────────────────────┘
   ↓ (se válido)
┌─────────────────────────────────────┐
│ 4. Business Logic                   │ ← fullSync, etc
│    (endpoints específicos)          │
└─────────────────────────────────────┘
   ↓
┌─────────────────────────────────────┐
│ 5. Error Handling                   │ ← Sem detalhar
│    (sem stack trace ao client)      │
└─────────────────────────────────────┘
   ↓
┌─────────────────────────────────────┐
│ 6. Response + Headers               │ ← Security headers
│    (CSP, HSTS, etc - Task 1.3)     │ ← 200 OK ou erro
└─────────────────────────────────────┘
```
