═══════════════════════════════════════════════════════════════════════════════

1. GitHub Secrets are ENCRYPTED
   - Never share your DEPLOY_SSH_KEY
   - Once added, values cannot be viewed again
   - If you lose them, generate new SSH key and reconfigure

2. SSH Key Security
   - DEPLOY_SSH_KEY goes to GitHub Secrets (encrypted)
   - Public key goes to VPS ~/.ssh/authorized_keys
   - Private key stays on your computer (~/.ssh/id_rsa_deploy)
   - NEVER commit private key to git

3. VPS Access
   - Must have SSH access to 145.223.94.296
   - Must be able to add SSH key to authorized_keys
   - If locked out, you may need VPS provider support

4. GitHub Actions
