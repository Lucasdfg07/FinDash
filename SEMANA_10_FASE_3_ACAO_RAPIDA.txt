PASSO 1: Gerar SSH Key (1 min)
───────────────────────────────────────────────────────────────────────────────

No seu computador, abra terminal e execute:

$ ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa_findash_deploy -N ""

✅ Isso cria 2 arquivos:
   - ~/.ssh/id_rsa_findash_deploy (PRIVADO - para GitHub)
   - ~/.ssh/id_rsa_findash_deploy.pub (PÚBLICO - para VPS)


PASSO 2: Adicionar Public Key ao VPS (3 min)
───────────────────────────────────────────────────────────────────────────────

$ ssh root@145.223.94.196

# No VPS, execute:
$ mkdir -p ~/.ssh
$ echo "$(cat ~/.ssh/id_rsa_findash_deploy.pub)" >> ~/.ssh/authorized_keys
$ chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys
$ exit

✅ Public key adicionada ao VPS


PASSO 3: Testar Conexão SSH (1 min)
───────────────────────────────────────────────────────────────────────────────

$ ssh -i ~/.ssh/id_rsa_findash_deploy root@145.223.94.196

✅ Se conectou SEM pedir senha, está correto!

$ exit


PASSO 4: Configurar GitHub Secrets (10 min)
───────────────────────────────────────────────────────────────────────────────

1. Vá para: https://github.com/seu-usuario/findash/settings/secrets/actions

2. Copiar Chave Privada:
   $ cat ~/.ssh/id_rsa_findash_deploy
   (Copie TUDO, do -----BEGIN ao -----END)

3. Adicionar Secret 1: DEPLOY_SSH_KEY
   - Click "New repository secret"
   - Name: DEPLOY_SSH_KEY
   - Value: Cole a chave privada
   - Click "Add secret"

4. Adicionar Secret 2: DEPLOY_HOST
   - Click "New repository secret"
   - Name: DEPLOY_HOST
   - Value: 145.223.94.196
   - Click "Add secret"

✅ Ambos os secrets adicionados


PASSO 5: Testar Workflow Manualmente (15 min)
───────────────────────────────────────────────────────────────────────────────

1. Vá para: https://github.com/seu-usuario/findash/actions

2. Selecione: "Deploy to Production" (no lado esquerdo)

3. Click: "Run workflow"

4. Selecione: branch = main

5. Click: "Run workflow"

✅ Aguarde 8-12 minutos
✅ Veja os jobs rodando em tempo real
✅ Ambos devem passar: test-and-build ✅ e deploy ✅


PASSO 6: Testar Auto-Deploy (10 min)
───────────────────────────────────────────────────────────────────────────────

$ git add .
$ git commit -m "test: trigger ci/cd workflow"
$ git push origin main

✅ Vá para GitHub Actions
✅ Você deve ver um novo workflow rodando automaticamente
✅ Aguarde 8-12 minutos
✅ Ambos os jobs devem passar

🚨 COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

❌ "SSH authentication failed" no GitHub Actions
   ✅ Solução: Verificar que public key está em VPS
   ✅ Solução: Verificar DEPLOY_SSH_KEY tem BEGIN e END

❌ "docker-compose not found" no VPS
   ✅ Solução: SSH para VPS e instalar docker-compose

❌ "npm run lint: errors found"
   ✅ Solução: Rodar npm run lint localmente, corrigir e push

❌ "Health check failed"
   ✅ Solução: SSH para VPS, rodar docker-compose logs app
